What a tech does on day one

  1. Accept shop rules. No shortcuts. Heat is a tool. Edges decide if the job comes back.
  2. Open the vehicle that matches the bay: van, trailer, box, bumper, hood/roof.
  3. Run the lesson card. Watch a clip only if stuck.
  4. If the film already failed, match it in Field Home before touching heat again.
