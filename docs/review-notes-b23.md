# Review notes for version 1.1 (23)

Sandbox purchase, then restore with email:

1. Sign in with a Sandbox Apple Account.
2. Open Pricing and buy the Shop Pack or a Seat (sandbox).
3. When the purchase finishes, enter an email you can open and tap Save email.
4. Delete WRAP 911, then install this build again.
5. Open Pricing, tap Restore with email, enter that same email, and enter the 6-digit code from the email.

The purchase unlocks this phone for 12 months and does not auto-renew. Restore puts the same purchase back on this phone after the delete and reinstall. Payment is Apple In-App Purchase. The app has no website checkout and no field for a purchase code.
